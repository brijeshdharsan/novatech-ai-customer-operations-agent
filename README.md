# NovaTech AI Sales & Customer Operations Agent

An AI-powered customer operations and sales automation agent built using n8n and Google Gemini.

## Project Overview

NovaTech AI Sales Agent is designed to automate customer interactions, answer product-related questions, qualify potential customers, and capture sales leads.

##Business Problem

Businesses spend significant time responding to repetitive customer queries and manually managing potential sales leads. This can result in delayed responses and missed sales opportunities.

## Solution

This AI agent provides automated customer assistance, collects customer requirements, classifies sales leads, and stores qualified customer information.

## Key Features

- AI-powered customer conversations
- Product information assistance
- Customer requirement collection
- Lead qualification and priority classification
- Google Sheets integration for lead management
- Gmail notifications for important leads
- Conversational memory
- Tool integration

## Technologies Used

- n8n
- Google Gemini
- AI Agents
- Google Sheets
- Gmail
- Workflow Automation

## Workflow

Customer Message → AI Agent → Customer Assistance → Lead Qualification → Google Sheets → Email Notification

## Project Purpose

This project demonstrates practical applications of Generative AI, AI agents, and business process automation.
